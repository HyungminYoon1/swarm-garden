## 세 가지 항해 미션

| 미션 | 환경과 고민 | 시뮬레이션 제한 |
| --- | --- | --- |
| 바늘문 항해 | 두 바위 통로를 통과하면서 무리가 퍼지지 않도록 분리·응집 조절 | 65초, 유도 24초 |
| 횡풍 릴레이 | 꺾이는 집결 경로, 8초마다 뒤집히는 횡풍, 정렬과 회전 반응의 균형 | 75초, 유도 24초 |
| 위험권 구조 | 위험권을 돌아 대피, 모으기·피하기와 경계 우회 선택 | 75초, 유도 24초, 노출 0.65 무리·초 |

미션은 준비 상태에서 열립니다. 규칙을 정하고 화면을 클릭해 고정 유도점을 놓은 뒤 시작하세요. 도착 비율 75%, 결속 85%, 정렬 55%(바늘문) 또는 50%(횡풍·구조)를 동시에 1.5초 유지하면 현재 집결지를 확보합니다. 하나라도 부족하면 유지 시간은 초기화됩니다. 결속은 55px 안에 동료가 있는 개체 비율이며, 모든 거리와 도착 판정은 화면 가장자리가 연결된 토러스 기준입니다.

클릭·Enter는 유도점 배치, 방향키는 조준, Space 또는 **유도 끄기**는 해제입니다. 켜 둔 시뮬레이션 시간만 유도 예산을 씁니다. 소진되어도 관성과 규칙으로 항해를 계속할 수 있습니다. 빨간 개체는 실제 위험권 안에 있으며, 노출은 위험권 안의 무리 비율 × 시간으로 누적합니다. 1 무리·초는 전체 개체가 위험권에서 1초 보낸 양입니다.

미션은 판단 시간을 확보하는 0.6배속이고, 표시된 제한·유지·유도 시간은 모두 시뮬레이션 기준입니다. 언제든 일시정지해 규칙을 조절할 수 있으며, 숨긴 페이지는 정지하고 자동 재개하지 않습니다. 모든 사용자는 처음에 정지 상태로 시작하므로 동작 줄이기 설정에서도 갑자기 움직이지 않습니다. 성공·실패 뒤 **같은 시드 재도전**은 규칙을 유지한 채 동일한 초기 무리와 지형으로 다시 시작하고, **새 시드**는 다른 무리와 지형을 만듭니다. 재현 시드를 직접 입력할 수도 있습니다. 미션에서는 60개체와 지형을 고정해 목표 조건을 보존합니다.

목표·예산이 없는 **자유 실험**에서는 기존 40–280개체 조절, 포인터 유도, 최대 12개 장애물 배치가 그대로 가능합니다. 이 모델은 규칙 간 영향을 배우는 실험이며 실제 생물 군집의 정확한 예측 모델은 아닙니다.

개인 소개나 계정 없이 사용할 수 있습니다. 새로고침하면 실험 상태가 초기화됩니다.

참고 개념: [원문과 추가 학습](https://www.red3d.com/cwr/boids/). 구현은 이 저장소의 계산 모델과 UI로 작성했습니다.

## 실행 및 검증

Node.js 22 이상. 외부 패키지는 없습니다.

```sh
npm run dev -- 0
npm test
npm run check
```

기존 배포 설정은 main에 푸시하면 검증 후 dist만 GitHub Pages에 배포합니다. 이번 미션 변경은 로컬 검토용이며 커밋·푸시·배포하지 않았습니다. 계산 모델과 UI는 분리되어 있습니다. 현재 페이지를 닫으면 실험 상태가 사라지며 서버 업로드·계정·방문자 추적 기능은 없습니다. 호스팅 로그와 앱의 데이터 처리는 별개입니다.

LOCAL 모델 테스트는 대표 시드 21, 22, 35, 123, 9876에서 세 미션의 실제 이동 성공과 기본/흩어짐 규칙의 실패를 검사합니다. 모든 시드·플레이 방식의 성공이나 브라우저 사용성 검증을 의미하지 않습니다. 이번 변경의 실제 브라우저 QA는 메인 작업에 인계하며 이 저장소 기록은 `NOT_RUN`입니다.
