## 세 가지 항해 미션

| 미션 | 환경과 고민 | 시뮬레이션 제한 |
| --- | --- | --- |
| 바늘문 항해 | 두 바위 통로를 통과하면서 무리가 퍼지지 않도록 분리·응집 조절 | 65초, 유도 24초 |
| 횡풍 릴레이 | 꺾이는 집결 경로, 8초마다 뒤집히는 횡풍, 정렬과 회전 반응의 균형 | 75초, 유도 24초 |
| 위험권 구조 | 위험권을 돌아 대피, 모으기·피하기와 경계 우회 선택 | 75초, 유도 24초, 노출 0.65 무리·초 |

미션은 준비 상태에서 열립니다. 규칙을 정하고 화면을 클릭해 고정 유도점을 놓은 뒤 시작하세요. 도착 비율 75%, 결속 85%, 정렬 55%(바늘문) 또는 50%(횡풍·구조)를 동시에 1.5초 유지하면 현재 집결지를 확보합니다. 하나라도 부족하면 유지 시간은 초기화됩니다. 결속은 55px 안에 동료가 있는 개체 비율이며, 모든 거리와 도착 판정은 화면 가장자리가 연결된 토러스 기준입니다.

클릭·Enter는 유도점 배치, 방향키는 조준, Space 또는 **유도 끄기**는 해제입니다. 켜 둔 시뮬레이션 시간만 유도 예산을 씁니다. 소진되어도 관성과 규칙으로 항해를 계속할 수 있습니다. 빨간 개체는 실제 위험권 안에 있으며, 노출은 위험권 안의 무리 비율 × 시간으로 누적합니다. 1 무리·초는 전체 개체가 위험권에서 1초 보낸 양입니다.

미션은 판단 시간을 확보하는 0.6배속이고, 표시된 제한·유지·유도 시간은 모두 시뮬레이션 기준입니다. 언제든 일시정지해 규칙을 조절할 수 있으며, 숨긴 페이지는 정지하고 자동 재개하지 않습니다. 모든 사용자는 처음에 정지 상태로 시작하므로 동작 줄이기 설정에서도 갑자기 움직이지 않습니다. 성공·실패 뒤 **같은 시드 재도전**은 규칙을 유지한 채 동일한 초기 무리와 지형으로 다시 시작하고, **새 시드**는 다른 무리와 지형을 만듭니다. 재현 시드를 직접 입력할 수도 있습니다. 미션에서는 60개체와 지형을 고정해 목표 조건을 보존합니다.

목표·예산이 없는 **자유 실험**에서는 기존 40–280개체 조절, 포인터 유도, 최대 12개 장애물 배치가 그대로 가능합니다. 이 모델은 규칙 간 영향을 배우는 실험이며 실제 생물 군집의 정확한 예측 모델은 아닙니다.

## 항해 결과와 비교

종료하면 실제 틱에서 측정한 도착·결속·정렬 미달 시간, 연속 유지 끊김, 위험 노출이 가장 컸던 구간, 목표 중심까지 평균 거리를 표시합니다. 구간은 최대 1초이며 집결지가 바뀌면 나눕니다. 조건별 미달 시간은 겹칠 수 있습니다. 개체는 소멸하지 않아 손실 개체 수는 없고, 미달 조건이나 위험 노출을 설정의 인과적 효과로 해석하지 않습니다.

**같은 시드 재도전**은 현재 규칙으로 초기화합니다. **직전 시작 설정·시드로 재도전**은 직전 종료 실행의 실제 시작 규칙과 초기 조건을 복원합니다. 조작·중간 규칙 변경은 다시 수행해야 합니다. 직전 결과와 임무·시드가 같을 때만 확보 수·경과 시간·유도·위험 차이를 표시합니다. 비교 기준과 시드는 페이지 메모리뿐이며 새로고침하면 사라집니다.

## 기기 기록

계정과 서버 전송 없이 `swarm-garden-record-v1`에 규칙·잔상 설정, 최근 종료 결과 5개, 완료 임무 ID 최대 3개를 저장합니다. 설정 변경/실행 종료 때만 기록합니다. 최근 요약에는 임무·결과·시간·확보 수·유도·위험·미달 시간·유지 끊김만 있고 시드·좌표·경로·조작·개인정보·파일·날짜는 없습니다. 같은 임무의 반복 성공은 완료 수를 늘리지 않습니다. 새 페이지는 저장 설정을 사용하되 시드 21 준비 상태로 열립니다. 저장 불가/손상은 기본값과 현재 페이지 메모리로 대응하며 표시합니다.

같은 출처의 갤러리는 `web-lab-progress-v1`의 앱 ID별 `{completed,total,updatedAt}`만 읽습니다. 실제 기기에 저장된 독립 완료 임무 수를 기록하며 전체 임무는 3개입니다. 갱신 시각은 완료 날짜가 아닙니다. 15개 앱 whitelist/최대 15항목, 정수 `0 <= completed <= total <= 1000`, ISO UTC 시간, 8,192자 상한을 검증하고 정상 타 앱 항목은 보존합니다. 서버 순위나 공인 기록은 없습니다.

**설정·결과·완료 기록 지우기**는 실행을 정지하고 기본 설정으로 돌리며 이 앱의 개인 키와 공유 요약의 자기 항목만 삭제합니다. 다른 앱 기록은 삭제하지 않습니다. 손상된 공유 값은 덮어쓰지 않고 갱신/삭제 실패를 표시합니다. 로컬 저장은 기기 소유자가 편집할 수 있고, 여러 탭의 동시 갱신은 충돌할 수 있습니다.

참고 개념: [원문과 추가 학습](https://www.red3d.com/cwr/boids/). 구현은 이 저장소의 계산 모델과 UI로 작성했습니다.
